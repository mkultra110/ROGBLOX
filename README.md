# ROGBLOX

Roblox cheat hub. Pure C++ loader for Windows.

## Build the .exe

Requirements (one-time):
- Visual Studio 2022 with the **"Desktop development with C++"** workload
- CMake 3.20+ (bundled with VS, or from https://cmake.org/download/)
- Python 3 (for the build-time bundling step)

Then **double-click `build-exe.bat`**. It:
1. Regenerates `dist/rogblox.lua` (the script that runs inside Roblox)
2. Embeds it as a byte array into the C++ loader at build time
3. Compiles `cpp/loader/main.cpp` with MSVC
4. Drops the resulting `ROGBLOX.exe` in the repo root

The .exe is **fully self-contained** — no external files needed at
runtime. Send it to anyone, they double-click and it works.

## Use it

1. Double-click **`ROGBLOX.exe`**.
2. Click the big purple **Load** button.
3. The loader detects every installed executor (Solara / Wave / Xeno /
   Delta / Synapse X / Krnl / Fluxus / Script-Ware / AWP / Hydrogen /
   CelerNB), writes ROGBLOX into each one's autoexec folder, and
   launches Roblox.
4. Press **RightCtrl** in-game to toggle the menu.

After this one-time setup, just open Roblox normally and the menu
auto-loads.

## Why is there Lua at all?

Because **Roblox only executes Lua**. Any cheat menu that shows up
inside the game is Lua code running in Roblox's Luau VM. The C++
loader's job is to deliver that Lua into your executor; from your
perspective you only touch the C++ side.

The whole `cpp/` directory is the C++ side. `cpp/loader/` is what
`build-exe.bat` compiles into `ROGBLOX.exe`. `cpp/injector/` and
`cpp/payload/` are a **reference C++ executor** for users who want
to fork and build their own host (research / Roblox Studio only —
see `cpp/docs/HYPERION.md` for why it can't bypass Hyperion on the
production client).

## Manual loader (skip the .exe entirely)

Paste this into any executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/mkultra110/rogblox/main/src/main.lua"))()
```
